Observed Inbox/Portal visual pattern (we are adapting only the Inbox content area and preserving the game's sidebar):
- Dark navy full workspace with thin blue-gray borders and purple/magenta active accents.
- Left Messages column with date separators, sender/avatar icon, sender name, subject, time, and unread/task indicators.
- Tabs/filters: All, New, Tasks, Unread; search and compact action icons.
- Center message detail panel with sender identity, subject, timestamp, body, attachments/context cards.
- Right-side contextual rail with cards such as Stages/table and Next Match Preview.
- Action-required messages have a strong red/pink footer band with response buttons.
- Prominent magenta/pink Continue or task action button in the header area in FM26 references.

Observed press conference flow:
1. Inbox message titled like “Pre-Match press conference about to begin” opens a message detail/briefing state.
2. Briefing includes likely talking points, journalists in attendance, media influence/relationship, match preview, and red “Response Required” footer.
3. Footer actions include Attend Press Conference, Send Assistant, and Delegate Attendance.
4. Live press-room view has a header “Press Conference”, club badge/name, Press Room, journalist count, mood/body-language chip, large Leave Meeting button, journalist portrait/name/publication, large colored question bubble, and answer choices.
